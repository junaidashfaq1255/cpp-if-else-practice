# C++ Marks Grading Program

A simple beginner-level C++ program that takes a student's marks as input and determines the corresponding grade using `if`, `else if`, and `else` statements.

## 📌 Features

- Takes marks as user input
- Uses conditional statements
- Assigns grades based on marks
- Displays the final grade

## 📊 Grading System

| Marks | Grade |
|-------|-------|
| 80–100 | A |
| 60–79 | B |
| 50–59 | C |
| Below 50 | Fail |


## 🎯 Purpose

This project was created as a beginner C++ programming exercise to practice:

- Variables
- User input
- Output
- `if` statements
- `else if` statements
- `else` statements
- Basic conditional logic
